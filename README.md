# 📝 To-Do List App

A simple and user-friendly To-Do List application built using HTML, CSS, and JavaScript.

This project helps users manage their daily tasks by adding, completing, and deleting tasks easily.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using Local Storage
- Tasks remain saved even after refreshing the page
- Clean and simple user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
