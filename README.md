
# 📝 To-Do List App

A simple and user-friendly To-Do List application built using HTML, CSS, and JavaScript.

This application helps users organize their daily tasks by adding, completing, and deleting tasks.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using Local Storage
- Tasks remain saved after refreshing the page
- Simple and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript



## 📚 What I Learned

- DOM Manipulation
- JavaScript Event Handling
- Working with Arrays and Objects
- Local Storage
- Frontend Development Basics

## 💻 How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding your tasks!
